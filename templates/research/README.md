# research/

Findings from the **research** agent — questions the project could not answer
from inside itself, answered with evidence.

One file per question. Each carries the question as asked, the answer, the
sources, the strongest case against, and what could not be established.

Nothing here is a decision. When a finding settles something that spans the
frontend/backend boundary, the conclusion belongs in `memory/decisions.md`,
where the agents will actually look.
